# Rubric: How well did the support agent handle this customer?

## Fixing the problem

Did the agent actually resolve the customer's issue, rather than only talk about it?

- 1: The agent does nothing to fix the issue, or the customer ends the conversation with the problem unsolved.
- 3: The agent fixes part of the issue, or promises a fix without doing anything concrete in the conversation.
- 5: The agent fully resolves the issue, or takes a concrete action (refund, replacement, correction) that settles it.

## Clear next steps

Did the agent tell the customer exactly what happens next?

- 1: The agent gives no next step, so the customer is left not knowing what to expect.
- 3: The agent gives a vague next step, such as "we will look into it" with no detail or timeframe.
- 5: The agent gives specific next steps, such as what will happen, who does it and when, or what the customer should do.

## Not asking again

Did the agent avoid asking for information the customer had already given?

- 1: The agent repeatedly asks for details the customer already provided, such as the order number or the problem itself.
- 3: The agent asks for something the customer had already said once, or asks for more than it needs.
- 5: The agent uses what the customer said and asks only for information that is new and needed.
